# 同一订阅多设备管理指南：并发风控机制、局域网代理共享与防封实务

::: tip 💡 核心结论与速查清单
- **风控核心红线**：绝大多数商业机场限制**2–5 台设备同时在线**，更重要的是**限制“跨出口公网 IP 并发”**。若将同一订阅同时分享给不同城市的亲友，后台会在数分钟内将其判定为“公开倒卖”并触发自动熔断封号。
- **神技「Allow LAN」局域网共享**：在台式机、Mac 或软路由上开启「允许局域网连接（Allow LAN）」，全屋的 iPhone、iPad、Apple TV、Switch 和智能电视只需在 WiFi 设置中填入电脑内网 IP 与 `7890` 端口，**即可全屋共享科学上网，在机场后台仅计为 1 台设备**！
- **家庭与团队选型法则**：多人家庭或外贸团队，切忌购买限制 1-2 台设备的小白套餐，应优先选择明确支持“不限设备并发”或“按 IP 限制”的大带宽专业服务商。
:::

## 一、机场后台多设备与 IP 并发风控机制大揭秘

很多用户疑惑：“我买了一个月 500GB 的大套餐，自己用不完，给异地的女朋友或同事一起用，为什么账号突然被系统注销了？”

```
机场后台风控系统（V2Board/SSPanel）并发监测模型：
情况 A：同局域网多设备（合规安全，不触发风控）
[手机 A] ──┐
[电脑 B] ──┼─> [家庭千兆路由器] ──(唯一公网 IP: 113.88.x.x)──> [机场入口] ──> ✅ 正常放行
[平板 C] ──┘

情况 B：异地跨公网多 IP 并发（高危！立即触发熔断）
[用户在深圳] (公网 IP: 113.88.x.x) ──> [发起连接] ──┐
                                                    ├──> [机场风控引擎检测到异地瞬时并发]
[朋友在北京] (公网 IP: 124.64.x.x) ──> [发起连接] ──┘         │
                                                              ▼
                                                   【判定为公开倒卖，自动熔断封禁】
```

### 1. 设备数限制 vs IP 并发限制
- **设备数限制（Device Limit）**：客户端每次向节点发起握手时，后端根据客户端生成的唯一标识符（Client Fingerprint）进行计数。超出套餐设定的阈值（如 3 台）后，第 4 台设备会遭遇连接无响应。
- **IP 并发限制（IP Limit）**：后端检测在同一时间窗口内，向同一订阅 Token 发起请求的外部公网 IP 数量。正规机场通常允许同一家庭公网 IP 下挂载多台设备，但**严禁多公网 IP 同时连接**。

## 二、利用「Allow LAN」零成本实现全屋设备共享

如果你家里有不支持直接安装 Clash 的设备（如 Apple TV、PlayStation 5、Nintendo Switch），或者不想为全家每台手机都配置一遍订阅，开启局域网共享是最佳方案。

```
                    ┌────────────────────────────┐
                    │   Allow LAN 全屋共享拓扑   │
                    └─────────────┬──────────────┘
                                  │
         【主机 PC / 软路由 (开启 Allow LAN，IP: 192.168.1.100)】
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
【Apple TV 电视盒子】       【任天堂 Switch】         【iPad / 备用手机】
WiFi HTTP 代理填入：       WiFi 代理设置填入：        WiFi 代理设置填入：
服务器: 192.168.1.100      服务器: 192.168.1.100     服务器: 192.168.1.100
端口: 7890                 端口: 7890                端口: 7890
```

### 1. 宿主机端（电脑）设置实操：
1. 打开 **Clash Verge Rev** 或任何 Clash 客户端；
2. 进入「设置」页面，找到 **「允许局域网连接 (Allow LAN)」** 并将其开启；
3. 记下端口号（默认通常为 `7890`）；
4. 打开 CMD 运行 `ipconfig`，查看电脑在当前家庭局域网的 IPv4 地址（例如 `192.168.1.100`）；
5. **重要**：在 Windows 防火墙弹窗中，务必勾选 **「允许专用网络与公用网络访问」**。

### 2. 接收端（手机/Switch/电视盒子）配置：
1. 连接同一个家庭 WiFi；
2. 点击当前 WiFi 旁边的感叹号 `(i)` 进入详情设置；
3. 滑到最底部，点击 **「配置代理」** 从“关闭”改为 **「手动」**；
4. **服务器**：填入电脑的局域网 IP（如 `192.168.1.100`）；
5. **端口**：填入 `7890`，认证保持关闭，点击右上角储存；
6. 此时该设备便能无缝走电脑代理，秒开 YouTube 与奈飞，**且在机场端仅计为电脑 1 台设备**！

## 五、常见问题深度解答 (FAQ)

<details>
<summary><strong>Q1：为什么我手机设置了局域网代理，但连不上电脑的 7890 端口？</strong></summary>
<p>
95% 的原因在于<strong>宿主电脑的「Windows Defender 防火墙」进行了入站拦截</strong>。解决方案：进入 Windows「控制面板」->「系统和安全」->「Windows Defender 防火墙」->「允许应用通过防火墙」，在列表中找到你的客户端软件（如 Clash Verge），确保「专用」和「公用」两个勾选框全部打上对勾；另外确保手机和电脑连接的是同一个 WiFi 名称，没有开启“AP 隔离”功能。
</p>
</details>

<details>
<summary><strong>Q2：宿主电脑如果休眠或合上笔记本盖子，手机还能继续上网吗？</strong></summary>
<p>
<strong>不能</strong>。手机的数据包是通过电脑上的客户端进程进行加密中转的。一旦电脑进入休眠、睡眠或断电，局域网代理服务立即终止，手机会直接断网。若需要 7×24 小时不间断的全屋代理，建议购置一台百元级的工控小主机（如 N100 / J4125）刷入 OpenWrt 软路由系统全天候运行。
</p>
</details>
