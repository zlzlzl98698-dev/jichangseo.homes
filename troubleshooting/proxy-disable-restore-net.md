# 关掉代理后电脑断网修复：注册表ProxyEnable清空与网络一键急救实操

::: tip 💡 核心结论与速查清单
- **典型症状**：关闭翻墙代理后，电脑右下角网络连接正常，**微信/QQ 文字语音收发如常，但 Edge、Chrome 等所有浏览器打开网页均报错 `ERR_PROXY_CONNECTION_FAILED`（无法连接到代理服务器）**。
- **故障底层真相**：客户端在运行时，会自动向 Windows 注册表写入全局系统代理指令（`ProxyEnable = 1`，指向 `127.0.0.1:7890`）。如果软件**异常崩溃、未通过托盘退出便直接关机或强杀进程**，注册表中的代理开关依然保持开启，而后台代理进程已死，导致浏览器向死端口发包陷入彻底断网！
- **极速自救三秒钟**：按 `Win + I` 打开设置 ➔ 点击 **「网络和 Internet」** ➔ 点击 **「代理」** ➔ 将 **「使用代理服务器」开关彻底关闭**，按 `F5` 刷新浏览器瞬间恢复！
:::

## 一、为什么会出现“微信能聊，但网页全瘫痪”？

这是由于不同软件在 Windows 系统内部调用网络协议栈的方式不同决定的：

```
系统代理残留引发的网络通信分层故障模型：
┌────────────────────────────────────────────────────────┐
│             Windows 操作系统网络请求总入口              │
└──────────────────────────┬─────────────────────────────┘
                           │
         ┌─────────────────┴─────────────────┐
         ▼                                   ▼
【走 WinINet 系统代理的应用】          【走物理网卡原生套接字的应用】
(Chrome / Edge / 网页版应用)          (微信桌面版 / QQ / 游戏对战)
         │                                   │
         ▼                                   ▼
读取注册表 ProxyEnable = 1            直接调用底层 TCP/IP 协议栈，
强行把流量发给 127.0.0.1:7890          完全忽略系统代理注册表！
         │                                   │
         ▼                                   ▼
❌ 7890 端口无服务，网页全部报错！     ✅ 正常收发消息，畅通无阻！
```

## 二、三大平台快速自救实操教程

### 方案 1：Windows 官方图形界面一键关闭（推荐小白）
1. 键盘按下快捷键 `Win + I` 唤出设置；
2. 左侧点击 **「网络和 Internet」**，右侧点击 **「代理」**；
3. 在“手动设置代理”下方，找到 **「使用代理服务器」**，将其设置为 **「关 (Off)」**，并点击 **「保存」**；
4. 回到浏览器按 `Ctrl + F5` 强制刷新，所有网页立即秒开。

---

### 方案 2：CMD / PowerShell 命令行两秒强制重置
若系统设置界面卡死打不开，以管理员身份运行 CMD，直接复制粘贴以下两行指令：
```cmd
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyServer /t REG_SZ /d "" /f
```
命令执行后无需重启电脑，注册表代理状态立即被强行擦除为关闭状态。

---

### 方案 3：底层网络协议栈彻底重置（针对顽固性断网）
如果关闭代理后，电脑依然打不开网页且局域网出现黄色感叹号，说明系统的网络目录（Winsock）发生了损坏：
1. 以管理员身份运行 CMD；
2. 依次输入以下三条重置命令：
   ```cmd
   netsh winsock reset
   netsh int ip reset
   ipconfig /flushdns
   ```
3. 执行完成后**重启计算机**，操作系统的所有网卡驱动与网络堆栈将被彻底恢复出厂初始状态。

---

### 方案 4：苹果 macOS 平台自救操作
苹果 Mac 用户若退出代理后 Safari 无法上网：
1. 点击屏幕左上角苹果图标 -> 进入 **「系统设置」->「网络」**；
2. 点击当前已连接的「Wi-Fi」或「以太网」旁的 **「详细信息」**；
3. 左侧点击 **「代理」** 标签；
4. 确保右侧的 **「网页代理 (HTTP)」** 和 **「安全网页代理 (HTTPS)」** 处于**未勾选**状态，点击好保存即可。

---

## 三、如何从根本上杜绝“关代理断网”重演？

1. **永远从右下角托盘规范退出**：需要关闭客户端时，**鼠标右键点击托盘图标选择「退出 (Quit)」**，软件在关闭前会自动向操作系统发送撤销代理的指令，绝不可在任务管理器中粗暴强杀；
2. **改用 TUN 虚拟网卡模式**：在 [Clash Verge Rev](/clients/clash-verge-rev) 中开启 TUN 模式并关闭传统的“系统代理”。TUN 模式工作在网络层，不篡改系统注册表，退出后自动销毁虚拟接口，从根源上免除了注册表残留隐患。
