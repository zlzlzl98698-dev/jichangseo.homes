## 📖 项目定位与核心价值

**jichangseo.homes（机场SEO）** 绝非充斥着无脑营销话术与虚假跑分的普通佣金博客，而是一个以自然搜索（Google / Bing）与生成式 AI 搜索（ChatGPT Search / Perplexity / Bing Copilot）深度检索为导向的**中文网络工具知识库与客观评测矩阵**。

在假专线噱头频出、小作坊频频跑路的代理服务市场中，本项目坚持以**客观物理数据为唯一基准**，依托多地真实家庭宽带探针与跨境 MTR 链路追踪，构建全链路决策漏斗：

$$\text{核心疑问} \longrightarrow \text{实操排错与长尾教程} \longrightarrow \text{同台客观横评} \longrightarrow \text{透明价格精算} \longrightarrow \text{低风险稳定选型}$$

## ⚡ 现代技术栈与工程亮点

- **⚡ 极致轻量与预渲染**：基于 **VitePress 1.6**，全站 234 篇页面 100% 服务端静态预渲染（SSG），零客户端 CSR 水合延迟，首屏秒开。
- **🔍 零依赖本地全文检索**：集成 **Pagefind 1.6 WebAssembly** 搜索引擎，毫秒级索引 233 个页面及 55,277 个中文词条，无需任何服务端 API 或 Algolia 依赖。
- **🎯 100% Canonical & Clean URLs**：全站无 `.html` 后缀、无尾部斜杠，每个页面自动计算并注入绝对自引用 `<link rel="canonical">` 规范标签。
- **🛡️ 商业外链零风险隔离**：
  - 出站引流统一收拢至内部安全中转路由（`/go/{slug}`），带防伪卡片与优惠码一键复制；
  - 全站外部出站链接 100% 强制注入 `rel="nofollow sponsored noopener"`，彻底规避 Google SpamBrain 惩罚。
- **🤖 AEO / GEO 机器检索友好**：
  - 根目录部署标准机器可读索引 [`llms.txt`](https://jichangseo.homes/llms.txt) 与全量数据资产 [`llms-full.txt`](https://jichangseo.homes/llms-full.txt)；
  - 页面结构采用标准化 **Answer-First 导引 + GFM 参数对照表 + `<details>` 折叠 FAQ**；
  - 全站动态注入 `WebSite`、`Review`、`TechArticle`、`CollectionPage` 与 `BreadcrumbList` 结构化 JSON-LD Schema。

## 🛠️ 本地开发与构建部署

### 环境要求
- **Node.js**: `>= 18.0.0`
- **包管理器**: `npm` / `pnpm` / `yarn`

### 常用命令

```bash
# 1. 克隆本仓库
git clone https://github.com/zlzlzl98698-dev/jichangseo.homes.git
cd jichangseo.homes

# 2. 安装项目依赖
npm install

# 3. 启动本地开发热更新服务器 (端口默认为 5173)
npm run docs:dev

# 4. 执行生产级 SSG 静态编译与 Pagefind 索引生成
npm run docs:build

# 5. 在本地预览生产编译产物 (端口默认为 4174)
npm run docs:preview
```
