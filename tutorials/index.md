## 二、使用前必要准备与安全防护认知基石

在执行任何软件安装前，请务必建立正确的安全底线：

1. **绝对不要安装未知来源的可执行文件**：
   * 严禁在百度、360 等搜索引擎置顶广告中下载所谓的“Clash 绿色免费破解版”；
   * 必须通过官方 GitHub Releases 代码仓库或本站提供的正规官方镜像渠道下载；
2. **强制校准操作系统本地系统时间**：
   * 现代 TLS 1.3、VMess 与 Trojan 协议高度依赖时间戳认证。**若本地系统时间与国际标准时间偏差超过 90 秒，所有节点将直接发生握手失败超时**；
   * 请在 Windows / Mac 设置中打开“自动设置时间”并点击“立即同步”。
3. **安全软件白名单放行**：
   * 代理内核在接管系统底层网络驱动（Wintun）时，部分第三方杀毒软件（如 360 安全卫士、火绒）可能会弹出风险驱动拦截拦截提示，请务必勾选“允许此程序所有操作”。

### 高阶实战：为什么必须开启 TUN 模式？
* **痛点**：普通【系统代理】仅对 Chrome、Edge 浏览器生效。当您使用命令行终端执行 `git clone`、`npm install`、`pip install`，或者启动 Steam、Discord 桌面端时，经常提示网络超时。
* **终极对策**：在 Clash Verge Rev【设置】中，开启【TUN 模式】并选择核心内核为【Mihomo】。程序会自动安装 Wintun 驱动，在操作系统底层虚拟出一张网络接口卡，强制拦截并透明转发全系统所有应用的所有网络报文！

## 五、macOS 操作系统环境无感配置与权限授权指南

苹果 macOS 系统拥有严苛的系统完整性保护（SIP）与权限隔离机制：

1. **版本选型红线**：
   * M1 / M2 / M3 / M4 芯片 Mac：必须下载带有 **`aarch64.dmg`** 后缀的原生安装包；
   * 老款 Intel 处理器 Mac：必须下载带有 **`x64.dmg`** 后缀的安装包；
2. **首次授权关键步骤**：
   * 打开软件后，如果系统提示“无法打开，因为无法验证开发者”，请进入 Mac【系统设置】->【隐私与安全性】，在安全性一栏点击【仍要打开】；
   * 在软件主界面开启代理功能时，如果提示安装 `Privileged Helper`，请输入 Mac 开机密码授权，这是客户端操作底层网络路由表的必要系统权限。

### 保证安卓手机 24 小时稳定不掉线的四大金刚法则：
1. **多任务卡片加锁**：进入手机后台多任务视图，下拉或长按客户端任务卡片，点击“小锁”图标，确保一键清理内存时不被关闭；
2. **电池无限制策略**：在手机【设置】->【应用管理】找到该客户端，点击【电池与省电策略】，由“智能推荐”修改为**“无限制 / 允许完全后台运行”**；
3. **开启自启动与关联启动权限**：允许客户端在开机或网络切换时自动在后台唤醒；
4. **精细化应用分流（Split Tunneling）实战**：
   * 在客户端设置中开启【分流应用 / 绕过模式】；
   * 勾选微信、支付宝、网易云音乐、拼多多等中国大陆高频应用，指定其**“完全绕过代理直接走本地网络”**。既节约套餐流量，又能彻底避免国内支付环境异常报警。

## 十、代理工作模式深度剖析：Rule vs Global vs Direct

| 运行模式 | 流量处理策略 | 优点剖析 | 缺点与隐患 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **规则模式 (Rule)** | 根据域名与 IP 数据库智能分流 | **国内直连、海外代理、广告拦截**，体验无缝 | 极小众冷门海外站点可能误判直连 | **99% 日常使用场景首选** |
| **全局模式 (Global)** | 所有外发流量一律强制走代理服务器 | 彻底杜绝漏球，强制隐藏真实公网 IP | 国内应用卡顿，严重浪费机场流量 | 临时排障、测试节点可用性 |
| **直连模式 (Direct)** | 所有流量完全不走代理，本地出站 | 相当于完全退出客户端，网速完全还原 | 无法访问任何海外受限平台 | 仅用于临时下载国内大文件 |

## 十一、底层转发核心机制：系统代理 vs TUN 虚拟网卡

```
+-----------------------------------------------------------------------------------------+
| 系统代理模式 (System Proxy) vs TUN 虚拟网卡模式 (TUN Mode) 底层报文对比                 |
+-----------------------------------------------------------------------------------------+

|   * 优势：全系统所有应用、后台开发工具、游戏客户端无死角全面透明接管                    |
+-----------------------------------------------------------------------------------------+
```

## 十二、DNS 最佳实践与防污染配置全方案

DNS 污染是跨国网络中最常见的干扰手段。要实现毫秒级快速响应与零污染解析，推荐在客户端中应用以下标准配置方案：

* **Fake-IP 模式解析机理**：
  * 当浏览器请求 `google.com` 时，客户端直接立即返回一个保留的假 IP（如 `198.18.0.2`），让本地 TCP 握手瞬间完成；
  * 真实域名被封装在加密报文中，直接发送给海外落地节点，由落地机在海外当地执行真实无污染 DNS 解析。不仅从物理上免疫本地 DNS 劫持，更能将网页建立连接的时间缩短 50% 以上。

## 十三、策略组分流架构：自动测速组、Fallback 容灾与负载均衡

优质机场的配置文件中通常预置了多层次策略组（Proxy Groups）：

1. **自动选择组（URL-Test / Auto）**：客户端每隔指定时间自动向基准服务器发送探针，动态将流量调度至当前延迟最低的专线节点；
2. **故障容灾组（Fallback）**：按列表顺序优先使用排在第一位的节点，只有当主节点发生超时宕机时，才自动顺位切换至备用节点；
3. **负载均衡组（Load-Balance）**：将高并发请求哈希散列到多个可用节点上，适合多线程批量数据抓取或 P2P 下载场景。

## 十四、订阅自动化运维：更新周期设定与订阅转换避坑

* **自动更新间隔设定**：在客户端中找到订阅属性，勾选“自动更新”并设置为 **1440 分钟（24 小时）**，既能及时同步节点变更，又不会对机场服务器造成过大轮询压力；
* **谨慎使用公共第三方订阅转换 API**：网上的免费订阅转换网站存在巨大的隐私与凭证泄漏隐患，某些不良站点会在后台搜集用户的真实订阅链接并转卖节点。尽量使用机场自带的原生客户端订阅，或本地自建 Subconverter 工具。

## 十五、配置结果权威四步自检与泄漏验证法

在配置完毕后，请打开浏览器按以下标准四步进行可用性验证：

1. **第一步：验证海外访问连通性**：打开 `https://www.google.com`，确认能否在 1 秒内正常加载并进行搜索；
2. **第二步：核对出口真实 IP**：访问 `https://ipinfo.io`，确认当前页面显示的 IP 归属地与您选中的节点国家（如香港、日本）一致；
3. **第三步：DNS 泄漏终极测试**：访问 `https://dnsleaktest.com`，点击【Standard Test】。**确认列表中绝不能出现中国三大运营商（电信/联通/移动）的 DNS 服务器**；
4. **第四步：WebRTC 纯净度检测**：访问 `https://browserleaks.com/webrtc`，确认公共 IP 地址列表中没有泄露本地宽带的真实中国 IP。
