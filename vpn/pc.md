## 一、电脑端两大底层接管模式：系统代理（System Proxy）vs TUN 模式

在电脑上使用科学上网软件时，很多用户经常发现：“为什么浏览器能打开 Google，但电脑终端里的 Git 报错连接超时，Steam 游戏也进不去？”。

这背后的根本原因在于电脑端的**两种不同流量接管机制**：

```
+-----------------------------------------------------------------------------------------+
| 桌面端系统代理 vs TUN 虚拟网卡机制全景解密                                              |
+-----------------------------------------------------------------------------------------+
| [模式 1: 系统代理 (System Proxy - 仅覆盖应用层 HTTP)]                                   |
|  * 运作方式：在 Windows 注册表或 macOS 网络设置中写入代理端口 (如 127.0.0.1:7890)        |
|  * 覆盖范围：仅对自觉遵守系统代理的主动应用有效 (如 Chrome/Edge 浏览器)                 |
|  * 局限性：无法接管终端命令行 (CMD/PowerShell)、无法接管外服游戏 UDP、无法接管网银直连   |
+-----------------------------------------------------------------------------------------+
| [模式 2: TUN 虚拟网卡模式 (TUN Mode - 网络层透明接管)]                                  |
|  * 运作方式：在电脑操作系统底层虚拟出一张高优先级虚拟网卡 (Wintun / Utun)               |
|  * 覆盖范围：在操作系统底层接管所有 TCP 与 UDP 数据包，实现 100% 真正全局透明加速        |
|  * 优势：Git 自动秒拉代码、Steam 联机不卡顿、无需手动给每个软件配置 7890 端口          |
+-----------------------------------------------------------------------------------------+
```

## 四、Windows 平台两大高发致命报错彻底修复方案

在 Windows 电脑上使用代理软件时，90% 的用户都会遇到以下两个经典故障，请妥善收藏自救方案：

### 故障 1：关掉软件后，电脑所有网页打不开（微信能发消息）
* **故障根因**：客户端异常强退或崩溃，未能向 Windows 注册表发送“还原代理”指令。系统依然在向已经关闭的 `127.0.0.1:7890` 发送请求；
* **一秒彻底根治法**：
  * 按快捷键 `Win + i` 打开系统设置 → 点击【网络和 Internet】→ 点击【代理】；
  * 在【手动设置代理】一栏中，将【使用代理服务器】的开关**手动切换为【关】**，点击保存。浏览器网页瞬间恢复正常。

### 故障 2：软件启动报错“端口被占用 / 7890 已经被其他进程监听”
* **故障根因**：老旧的 CFW 进程残留未退出，或被迅雷、360 等软件占用了本地 7890 端口；
* **一键强杀清理法**：
  * 右键开始菜单选择【Windows 终端 (管理员)】，输入以下命令查询并强杀：
    ```powershell
    # 查找占用 7890 端口的进程 PID
    netstat -ano | findstr :7890
    # 强制杀死该进程 (将 PID 替换为查询到的数字)
    taskkill /F /PID <PID数字>
    ```

## 六、电脑端使用常见核心疑问深度解答（FAQ）

<details>
<summary><strong>Q1：很多年前流行的 Clash for Windows（CFW）还能继续使用吗？</strong></summary>
<p>强烈建议立即淘汰卸载。原版 CFW 的开发者早在 2023 年底已删库停止维护，其内置的 Electron 框架与 Clash 核心存在未修复的高危安全漏洞，且不支持新一代 VLESS 等高性能协议。现代 Windows 用户应首选由开源社区持续活跃维护的 <strong>Clash Verge Rev</strong>，其安全性与性能均全面胜出。</p>
</details>

<details>
<summary><strong>Q2：电脑一直开着代理软件，会影响我打国服《英雄联盟》或玩腾讯游戏吗？</strong></summary>
<p>只要保持在【规则分流（Rule）】模式下，完全没有任何影响。规则模式会自动判断游戏服务器 IP。如果是腾讯、网易等国内游戏服务器，本地流量会以 0 延迟直接走你家物理宽带直连，绝不会经过海外机场，国服 Ping 值完全不受干扰。</p>
</details>

<details>
<summary><strong>Q3：为什么电脑上看 YouTube 4K 很顺畅，但下载大型文件速度只有几兆？</strong></summary>
<p>YouTube 视频播放采用多连接切片自适应流，能充分榨干并发带宽；而某些网盘或直接 HTTP 下载属于“单线程（Single-Connection）”传输。单线程速度深受跨境物理专线延迟与 TCP 拥塞算法影响。搭配企业级纯专线机场（如光速云），能最大限度提升单线程吞吐，单文件下载速度可轻松突破 50MB/s。</p>
</details>

<details>
<summary><strong>Q4：公司的办公电脑通常安装了企业安全监控软件，挂代理会被网管发现吗？</strong></summary>
<p>会。如果公司安装了深信服、EDR 或企业级安全证书，企业监控软件能够直接检测到本地监听的 7890 端口以及大量的虚拟网卡流量，甚至能够对公司内网实施 DPI 审计。在公司严格管制的办公电脑上，切勿擅自运行任何未经批准的翻墙软件，建议使用个人手机热点进行独立出海浏览。</p>
</details>
